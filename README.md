# SafeKit Packages & Documentation Download

SafeKit high availability software packages and attached documentation.

SafeKit is an all-in-one high availability software that combines real-time file replication, automatic failover, and load balancing — no shared storage (SAN) required.

> [!TIP]
> **[⬇️ Download the latest version](https://github.com/FR-LES-SAFEKIT-DEV/safekit-packages/releases/latest)**

## Installation Packages

| Platform               | File                                                                 | Description                                                                                               |
| ---------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Windows (Intel 64-bit) | `.exe` Installer                                                     | Includes Microsoft VC++ Redistributable                                                                   |
| Windows (Intel 64-bit) | `.msi` Installer                                                     | Does not include Microsoft VC++ Redistributable                                                           |
| Linux (Intel 64-bit)   | `.bin` Self-extracting <br> `.sha256` Checksum <br> `.gpg` Signature | Includes Linux package and installation script <br> Integrity verification <br> Authenticity verification |
| Linux (ARM 64-bit)     | `.bin` Self-extracting <br> `.sha256` Checksum <br> `.gpg` Signature | Includes Linux package and installation script <br> Integrity verification <br> Authenticity verification |
